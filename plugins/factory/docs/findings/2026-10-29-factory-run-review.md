2. Generated files in the repo: CLAUDE.md says `plugins/` is generated by a script with a `--check`; the feature touches a generated file. Expect the spec to name the generator and the reviewer/approver to flag a hand-edit (L1).
3. Auto-mode start: spawn failure text surfaced, worktree cleaned (L5, L6).
4. "Do not push" in the feature vs the open-PR step: expect no push instruction and no "PR opened" state (L3).
5. Stale worktree cleanup after a failed start (L6).
6. Approve without running checks / builder reports failing tests: expect ESCALATE, not APPROVE (L2, S6).
7. Review scope: a deliverable outside the diff; expect the verdict to say it was not reviewed (L7, L10).
8. Base ahead of upstream: expect a warning listing the extra commits (L4).
9. Feature text naming the repo root path: expect agents to stay in the worktree (L9).
